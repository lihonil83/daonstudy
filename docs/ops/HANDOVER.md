# HANDOVER.md

이 문서는 미해결 문제, 반복 실패 이슈, 환경 제약, 사용자 확인 대기 사항을 다음 작업자가 바로 이어받을 수 있도록 기록하는 운영 로그다.

기록 원칙:

- 해결되지 않은 활성 이슈를 위에 둔다.
- 시도는 추상적으로 쓰지 말고, 실제 수정과 검증 결과를 짧게 남긴다.
- 다음 작업자가 첫 번째 행동을 바로 알 수 있어야 한다.
- 해결된 항목은 삭제하지 말고 `해결됨` 상태로 남기거나 하단으로 이동한다.
