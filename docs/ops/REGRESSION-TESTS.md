# REGRESSION-TESTS.md

이 문서는 `다온 학습(Daon Study)`의 새로운 기능 배포나 구조 변경 시 기존 기능이 망가지지 않았는지(회귀 버그) 점검하는 **수동 수동 검증 체크리스트**입니다. 
본 프로젝트는 단위 테스트(Jest 등) 코드를 작성하지 않는 1인 개발(`AGENTS.md` 헌법 참고)이 원칙이므로, 브라우저를 통한 시각적/기능적 확인이 공식적인 회귀 테스트 방안이 됩니다.

---

- [ ] YYYY-MM-DD: `[버전명 또는 작업명]` (진행자: 작성자명)

## ✅ 1. 라우팅 & 네비게이션
로드맵, 복습, 기록, 설정 등 하단(또는 상단) 탭을 통한 기본 페이지 이동이 끊김 없이 부드러운가?
- [ ] `홈(로드맵)` 페이지 진입 시 선택된 학년의 단원 그리드가 정상 렌더링된다.
- [ ] `복습` 페이지는 작성해둔 오답이 존재할 시, 모아보기/연습 시작 UI가 뜬다.
- [ ] `기록` 페이지의 그래프 수치, 등급 카드, 뱃지 등이 정상 노출된다.
- [ ] `설정` 페이지의 화면 내용 겹침이 없다.

## ✅ 2. 문제 생성 엔진 (핵심 기능)
Gemini 기반 실시간 퀴즈 생성 로직과 오류 처리가 명확한가?
- [ ] `설정`에서 유효한 API 키 저장 후, 연결 테스트 시 "연결 성공" 응답이 뜬다. (API 키는 `••••` 형태 유지)
- [ ] 로드맵 특정 단원 클릭 시 퀴즈 생성 과정(스피너 표시 등)이 보여진다.
- [ ] 생성 완료 시점, 모달이 닫히며 퀴즈 화면으로 10문제가 성공적으로 이동(& 로컬 캐시 적용)된다.
- [ ] 틀린 API 키(`AIzaSy...dummy`) 사용 후 퀴즈 생성 클릭 시, 무한 로딩 대비 명확한 에러("모델 설정을 확인해 주세요" 등) 팝업이 노출된다.

## ✅ 3. 반응형 레이아웃 오작동 점검 (UI 깨짐 방지)
데스크톱(100vh), 서피스북 창 모드, 모바일 등 극단적으로 좁거나 낮은 비율에서의 레이아웃
- [ ] `로드맵 상단 학년(Grade) 탭`이 폭이 좁은 창에서 서로 뭉개지거나 영역을 벗어나지 않고 가로 스크롤로 매끄럽게 넘어간다. (Gradio UI 개선 확인)
- [ ] `진도, 기록 요약 카드`들이 좁은 창에서 찌그러지지 않고 세로로 정렬(Flex Column)된다.
- [ ] 하단 네비게이션 바가 화면 가장 아래쪽에 안정적으로 고정되어 컨텐츠 영역(Footer/Body)를 덮어 가리지 않는다.

## ✅ 4. 퀴즈 동작 환경
- [ ] 화면 우측 상단 `자동화 모드(개발자용)` 작동 및 정지 확인.
- [ ] 정답/오답 클릭 시 사운드 이펙트(팡파르 등) 발생 확인.
- [ ] 퀴즈 오답 발생 시, 즉각 복습/나중에 복습 후 퀴즈가 재개/종료 되는 순서 확인.
