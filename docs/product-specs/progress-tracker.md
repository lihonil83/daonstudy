# Product Spec: 진도/점수 기록

## 개요

퀴즈 결과를 누적 기록하고, 아이가 "나 이만큼 했다!"를 한눈에 볼 수 있게 한다.
부모도 학습 현황을 파악할 수 있다.

---

## 기록 대상

| 항목 | 저장 위치 | 설명 |
|------|-----------|------|
| 퀴즈 점수 히스토리 | `eduapp_scores` | 날짜별 퀴즈 결과 누적 |
| 과목별 진도 | `eduapp_progress` | 단원 완료 여부, 최고 점수 |
| 학습 일수 | `eduapp_scores`에서 계산 | 연속 학습일, 총 학습일 |

---

## 데이터 구조

### eduapp_scores (퀴즈 점수 히스토리)

```json
[
  {
    "id": "score-20260328-001",
    "date": "2026-03-28",
    "subject": "math",
    "unit": "multiplication-3",
    "unitTitle": "구구단 3단",
    "score": 8,
    "total": 10,
    "stars": 2,
    "xpEarned": 85,
    "duration": 180
  }
]
```

- `stars`: 별 등급 (1~3)
- `duration`: 소요 시간 (초 단위, 참고용 — 압박 목적 아님)
- 최근 기록이 배열 뒤에 추가됨

### eduapp_progress (과목별 진도)

```json
{
  "math": {
    "units": {
      "multiplication-2": { "bestScore": 10, "bestStars": 3, "attempts": 5, "firstClear": "2026-03-25" },
      "multiplication-3": { "bestScore": 8, "bestStars": 2, "attempts": 2, "firstClear": "2026-03-28" }
    }
  },
  "english": {
    "units": {
      "alphabet-upper": { "bestScore": 9, "bestStars": 2, "attempts": 3, "firstClear": "2026-03-26" }
    }
  }
}
```

- `bestScore`: 해당 단원 최고 점수 (갱신 시만 업데이트)
- `attempts`: 도전 횟수 (몇 번이나 했는지 → 노력 보상용)
- `firstClear`: 첫 완료 날짜

## 화면: 진도 페이지

### 상단 — 전체 요약

```
┌─────────────────────────────┐
│                             │
│  📊 나의 학습 기록           │
│                             │
│  총 학습일: 12일             │
│  연속 학습: 🔥 3일째!        │
│  푼 퀴즈: 28회               │
│                             │
└─────────────────────────────┘
```

- 연속 학습은 긍정적 표현 (🔥 아이콘, "대단해!" 멘트)
- 0일이어도 "오늘 시작해볼까?" (죄책감 금지)

### 중단 — 과목별 단원 진도

```
┌─────────────────────────────┐
│  🔢 수학                    │
│                             │
│  구구단 2단  ⭐⭐⭐  5회 도전 │
│  구구단 3단  ⭐⭐    2회 도전 │
│  구구단 4단  🔒 아직 안 함   │
│                             │
│  🔤 영어                    │
│                             │
│  알파벳 대문자 ⭐⭐  3회 도전 │
│  알파벳 소문자 🔒 아직 안 함  │
└─────────────────────────────┘
```

- 🔒는 "못한다"가 아니라 "아직 안 함" — 자유롭게 도전 가능
- 별 표시로 최고 기록 한눈에 확인
- 도전 횟수 표시 → 노력을 인정하는 느낌

### 하단 — 최근 퀴즈 기록

```
┌─────────────────────────────┐
│  📝 최근 기록                │
│                             │
│  3/28  구구단 3단  8/10 ⭐⭐  │
│  3/28  알파벳     9/10 ⭐⭐  │
│  3/27  구구단 2단 10/10 ⭐⭐⭐ │
│  3/26  구구단 2단  7/10 ⭐⭐  │
│                             │
│  [ 더 보기 ]                 │
└─────────────────────────────┘
```

- 최근 10개까지 기본 표시
- 날짜 + 단원 + 점수 + 별 등급
- 점수가 이전보다 올랐으면 📈 표시 ("실력이 늘고 있어!")

## useProgress 훅 인터페이스

```javascript
const {
  // 기록 저장
  saveQuizResult,      // (result) → scores, progress, reward 모두 업데이트

  // 전체 통계
  totalStudyDays,      // 총 학습일 수
  currentStreak,       // 연속 학습일
  totalQuizCount,      // 총 퀴즈 횟수

  // 과목별 진도
  getUnitProgress,     // (subject, unitId) → { bestScore, bestStars, attempts }
  getAllUnits,          // (subject) → 전체 단원 진도 배열

  // 점수 히스토리
  recentScores,        // 최근 10개 퀴즈 기록
  getScoresBySubject,  // (subject) → 해당 과목 기록만
  getScoresByDate,     // (date) → 해당 날짜 기록만
} = useProgress();
```

## 진도 계산 로직

### 연속 학습일 계산

```
오늘 날짜부터 거꾸로 확인:
- 오늘 기록 있음 → streak = 1
- 어제 기록 있음 → streak = 2
- 그저께 기록 있음 → streak = 3
- 없는 날 만나면 → 중단
```

### 최고 점수 갱신

```
새 점수 > 기존 bestScore → bestScore 업데이트, bestStars 업데이트
새 점수 ≤ 기존 bestScore → 변경 없음
attempts는 항상 +1
```

### 점수 추이 표시

```
이전 같은 단원 점수 대비:
- 올랐으면 → 📈 "실력이 늘고 있어!"
- 같으면 → 표시 없음
- 내렸으면 → 표시 안 함 (부정적 피드백 금지)
```

## 완료 기준

- `saveQuizResult` 호출 한 번으로 점수 히스토리와 과목별 진도 데이터가 함께 갱신된다.
- 진도 페이지에서 전체 요약, 과목별 단원 진도, 최근 퀴즈 기록 3개 영역을 확인할 수 있다.
- 연속 학습일, 총 학습일, 총 퀴즈 수가 저장된 기록 기준으로 일관되게 계산된다.
- 최고 점수와 도전 횟수는 누락 없이 반영되며, 점수 하락은 부정적으로 강조하지 않는다.
- 기록이 없어도 빈 상태 메시지로 자연스럽게 시작할 수 있다.

## 실패/중단 조건

아래 중 하나라도 발생하면 이 스펙은 완료로 보지 않는다.

- 점수 저장은 되었는데 `eduapp_progress` 또는 `eduapp_scores` 한쪽만 갱신된다.
- 연속 학습일 계산이 날짜 기준과 다르거나 같은 날 중복 기록 처리로 왜곡된다.
- 최고 기록보다 낮은 점수를 전면에 노출해 부정적 피드백을 준다.
- 기록이 없을 때 화면이 깨지거나 기본값 없이 실패한다.

## 리스크 & 주의사항

| 리스크 | 대응 |
|--------|------|
| localStorage 용량 (5MB 제한) | 점수 기록 최대 500개, 초과 시 오래된 것부터 삭제 |
| 브라우저 데이터 삭제로 기록 소실 | 향후 JSON 내보내기/가져오기 기능 고려 |
| 점수 하락 시 의욕 저하 | 점수 하락은 표시하지 않음, 최고 기록만 강조 |
| 숫자에 집착 | 도전 횟수(노력)도 함께 표시하여 과정을 인정 |
