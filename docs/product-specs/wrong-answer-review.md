# Product Spec: 오답 복습

## 개요

틀린 문제를 모아서 다시 풀 수 있게 한다.
"틀린 건 나쁜 게 아니라, 다시 배울 기회"라는 메시지를 전달한다.

---

## 오답 저장 흐름

```
퀴즈 중 최종 오답 발생
  → eduapp_wrong에 자동 저장
  → 퀴즈 결과 화면에서 "틀린 문제 복습하기" 버튼 표시

복습 페이지 진입
  → 미복습 오답 목록 표시
  → "복습 시작" → 오답만으로 퀴즈 진행
  → 복습 완료 → reviewed: true 표시 + XP 획득
```

## 데이터 구조

### eduapp_wrong

```json
[
  {
    "id": "wrong-20260328-001",
    "originalQuestionId": "mul3-005",
    "subject": "math",
    "unit": "multiplication-3",
    "unitTitle": "구구단 3단",
    "question": "3 × 5 = ?",
    "choices": [12, 15, 18, 20],
    "userAnswer": 12,
    "correctAnswer": 15,
    "hints": ["3을 5번 더해봐!", "3 + 3 + 3 + 3 + 3 = ?"],
    "visual": null,
    "date": "2026-03-28",
    "reviewed": false,
    "reviewedDate": null,
    "reviewCorrect": null
  }
]
```

- `reviewed`: 복습 완료 여부
- `reviewCorrect`: 복습 시 맞혔는지 여부 (통계용)
- `visual`: 시계처럼 시각 자료가 필요한 문제의 렌더링 정보 (없으면 `null`)
- 같은 문제를 여러 번 틀리면 가장 최근 것만 유지 (중복 방지)

## 화면: 복습 페이지

### 오답 목록 화면

```
┌─────────────────────────────┐
│                             │
│  📖 오답 노트                │
│                             │
│  미복습 3개 | 복습완료 5개    │
│                             │
│  ── 미복습 ──                │
│  🔢 3×5=? (3/28)    [복습]  │
│  🔢 7×8=? (3/28)    [복습]  │
│  🔤 d↔D 매칭 (3/27) [복습]  │
│                             │
│  ┌──────────────────────┐   │
│  │  전체 복습 시작 (3문제) │  │
│  └──────────────────────┘   │
│                             │
│  ── 복습 완료 ✅ ──          │
│  🔢 2×9=? (3/26)    ✅ 정답 │
│  🔢 4×7=? (3/25)    ✅ 정답 │
│  ...                        │
└─────────────────────────────┘
```

- 미복습 문제가 위에, 복습 완료가 아래
- 개별 복습(1문제) 또는 전체 복습(미복습 전부) 선택 가능
- 복습 완료 문제는 ✅ 표시 + 맞혔는지 여부

### 복습 퀴즈 화면

일반 퀴즈와 동일한 UI를 사용하되, 차이점:

| 항목 | 일반 퀴즈 | 복습 퀴즈 |
|------|-----------|-----------|
| 문제 수 | 10문제 고정 | 미복습 문제 수만큼 |
| 출제 순서 | 랜덤 셔플 | 랜덤 셔플 |
| 힌트 | 2회 제공 | 2회 제공 (동일) |
| XP | 정답 +10/+5 | 정답 +10/+5 |
| 완료 보너스 | +20 | +30 (복습 보너스) |
| 헤더 텍스트 | "구구단 3단" | "📖 오답 복습" |

### 복습 결과 화면

```
┌─────────────────────────────┐
│                             │
│  📖 복습 완료!               │
│                             │
│  3문제 중 2개 정답!          │
│                             │
│  ✅ 3×5=? → 맞혔어!         │
│  ✅ 7×8=? → 맞혔어!         │
│  ❌ d↔D → 다음에 다시!       │
│                             │
│  +50 XP 획득! (복습 보너스)  │
│                             │
│  ┌──────┐  ┌──────┐        │
│  │  홈  │  │ 다시  │        │
│  └──────┘  └──────┘        │
└─────────────────────────────┘
```

- 복습에서 맞힌 문제: `reviewed: true`, `reviewCorrect: true`
- 복습에서도 틀린 문제: `reviewed: false` 유지 → 다음 복습에 다시 나옴
- 복습에서도 틀린 건 "다음에 다시!" 톤 (좌절감 방지)

## 오답 관리 로직

### 중복 처리

```
같은 originalQuestionId로 다시 틀린 경우:
  → 기존 오답 항목의 date를 최신으로 갱신
  → reviewed를 false로 리셋
  → 새 항목을 추가하지 않음
```

### 오답 정리

```
- 복습에서 맞힌 문제 → reviewed: true (목록 하단으로 이동)
- 복습에서도 틀린 문제 → reviewed: false 유지 (계속 미복습 상태)
- 오답 최대 100개 유지, 초과 시 reviewed: true인 것 중 오래된 것부터 삭제
```

### 홈 대시보드 연동

```
미복습 오답이 있을 때 홈에 표시:
  "📖 복습할 문제가 3개 있어!"
  [복습하러 가기] 버튼

미복습이 0개일 때:
  "✨ 복습할 문제가 없어! 대단해!"
```

## useWrongAnswers 훅 인터페이스 (useQuiz 내부에서도 사용)

```javascript
const {
  // 오답 목록
  unreviewedList,     // 미복습 오답 배열
  reviewedList,       // 복습 완료 오답 배열
  unreviewedCount,    // 미복습 개수
  
  // 저장
  addWrongAnswer,     // (wrongData) → 오답 저장 (중복 시 갱신)
  
  // 복습
  markReviewed,       // (id, correct) → 복습 완료 처리
  
  // 정리
  clearReviewed,      // 복습 완료 항목 전부 삭제 (수동)
} = useWrongAnswers();
```

## 완료 기준

- 최종 오답이 발생하면 해당 문제가 `eduapp_wrong`에 저장되고 결과 화면에서 복습 진입 경로가 보인다.
- 복습 페이지에서 미복습/복습 완료 목록이 구분되어 보이고, 개별 복습과 전체 복습을 모두 시작할 수 있다.
- 복습 퀴즈는 미복습 문제만 사용하며, 맞힌 문제는 `reviewed: true`, `reviewCorrect: true`로 갱신된다.
- 복습에서도 틀린 문제는 `reviewed: false`로 유지되어 다음 복습에 다시 나타난다.
- 복습 완료 보너스 XP와 홈 대시보드 알림이 스펙대로 연결된다.

## 실패/중단 조건

아래 중 하나라도 발생하면 이 스펙은 완료로 보지 않는다.

- 같은 `originalQuestionId`가 중복 항목으로 계속 쌓여 최신 상태를 유지하지 못한다.
- 복습에서 맞힌 문제가 다시 미복습 목록에 나타나거나, 틀린 문제가 사라진다.
- 복습 모드가 일반 퀴즈와 구분되지 않아 헤더/문제 수/보너스 규칙이 섞인다.
- 미복습 문제가 0개일 때 빈 상태 처리가 없거나 홈 알림이 실제 상태와 다르다.

## 리스크 & 주의사항

| 리스크 | 대응 |
|--------|------|
| 오답이 쌓여서 복습이 부담됨 | 미복습 개수를 가볍게 표시, 강제하지 않음 |
| 같은 문제 계속 틀려서 좌절 | 틀려도 "다음에 다시!" 톤, 힌트 유지 |
| 복습을 안 하면 기능 무용지물 | 홈에 가벼운 알림 + 복습 XP 보너스로 유도 |
| 오답 데이터 과다 | 최대 100개, 복습 완료된 오래된 것부터 정리 |
| 복습에서 맞힌 문제를 또 복습 | reviewed: true인 건 복습 퀴즈에 안 나옴 |
