# Product Spec: 보상/레벨업 시스템

## 개요

"한 판 더 하고 싶다"를 만드는 시스템.
XP를 모아 레벨업하고, 뱃지를 수집하면서 성취감을 느끼게 한다.

---

## XP (경험치) 시스템

### XP 획득 규칙

| 행동 | XP | 비고 |
|------|-----|------|
| 정답 (바로 맞힘) | +10 | 기본 보상 |
| 정답 (힌트 후 맞힘) | +5 | 노력 인정 |
| 오답 (최종) | +0 | 벌점 없음 |
| 퀴즈 완료 보너스 | +20 | 끝까지 푼 것 자체를 보상 |
| 만점 보너스 | +50 | 10/10 추가 보상 |
| 오답 복습 완료 | +30 | 복습을 한 것 자체를 보상 |

### XP 계산 예시

```
10문제 중 8개 바로 정답, 1개 힌트 후 정답, 1개 오답:
  바로 정답: 8 × 10 = 80
  힌트 후:   1 × 5  = 5
  오답:      1 × 0  = 0
  완료 보너스:        20
  ──────────────────────
  총 XP:             105
```

## 레벨 시스템

### 레벨업 기준

| 레벨 | 필요 누적 XP | 칭호 |
|------|-------------|------|
| 1 | 0 | 🌱 새싹 학습자 |
| 2 | 100 | 🌿 열심히 하는 학습자 |
| 3 | 250 | 🌳 성장하는 학습자 |
| 4 | 500 | ⭐ 똑똑한 학습자 |
| 5 | 800 | 🌟 빛나는 학습자 |
| 6 | 1200 | 💫 대단한 학습자 |
| 7 | 1700 | 🔥 불꽃 학습자 |
| 8 | 2300 | 🏆 챔피언 학습자 |
| 9 | 3000 | 👑 마스터 학습자 |
| 10 | 4000 | 🐉 전설의 학습자 |

- 레벨 간격이 점점 넓어짐 → 초반에 빠르게 레벨업해서 재미를 느끼게
- 레벨 10 이후에도 XP는 계속 쌓임 (한계 없음)
- 칭호는 홈 대시보드에 항상 표시

### 레벨업 화면

```
┌─────────────────────────────┐
│                             │
│     🎉🎉🎉                  │
│                             │
│     레벨 업!                 │
│                             │
│   🌿 → ⭐                   │
│   레벨 4 달성!               │
│   "똑똑한 학습자"            │
│                             │
│   (축하 애니메이션)           │
│                             │
│  ┌──────────────────────┐   │
│  │       계속하기        │   │
│  └──────────────────────┘   │
└─────────────────────────────┘
```

- 화면 전체를 사용하는 축하 이펙트 (컨페티/반짝임)
- 이전 칭호 → 새 칭호 변화 강조
- 2~3초간 자동 애니메이션 후 "계속하기" 버튼 활성화

## 뱃지 시스템

### 뱃지 설계 원칙

- **점수 기반이 아닌 행동 기반** → "잘하는 것"보다 "하는 것" 자체를 보상
- 달성 조건은 명확하게, 아이가 "이거 하면 받을 수 있겠다"를 알 수 있게
- 숨겨진 뱃지도 1~2개 (서프라이즈 재미)

### MVP 뱃지 목록

| 뱃지 | 아이콘 | 조건 | 유형 |
|------|--------|------|------|
| 첫 걸음 | 👶 | 첫 퀴즈 완료 | 도전 |
| 구구단 도전자 | 🔢 | 구구단 퀴즈 3회 완료 | 도전 |
| 영어 도전자 | 🔤 | 영어 퀴즈 3회 완료 | 도전 |
| 완벽주의자 | 💎 | 아무 단원이나 만점(10/10) 달성 | 성취 |
| 구구단 마스터 | 🏅 | 구구단 아무 단원 만점 3회 | 성취 |
| 복습왕 | 📖 | 오답 복습 3회 완료 | 노력 |
| 3일 연속 | 🔥 | 3일 연속 학습 | 습관 |
| 7일 연속 | 🔥🔥 | 7일 연속 학습 | 습관 |
| 30일 연속 | 🔥🔥🔥 | 30일 연속 학습 | 습관 |
| 비밀 뱃지 | 🎁 | 하루에 5회 이상 퀴즈 | 숨김 |

### 뱃지 획득 화면

```
┌─────────────────────────────┐
│                             │
│     🏅 새 뱃지 획득!         │
│                             │
│     "구구단 마스터"          │
│     구구단 만점 3회 달성!     │
│                             │
│  ┌──────────────────────┐   │
│  │       좋아요!         │   │
│  └──────────────────────┘   │
└─────────────────────────────┘
```

- 레벨업보다 가벼운 이펙트 (작은 팝업 + 효과음)
- 퀴즈 결과 화면에서 표시 (흐름을 끊지 않게)

## 홈 대시보드 보상 표시

```
┌─────────────────────────────┐
│                             │
│  ⭐ 레벨 4 — 똑똑한 학습자    │
│  ████████░░ 500/800 XP      │  ← XP 진행 바
│                             │
│  🏅 뱃지 4/10 수집           │
│  👶 🔢 💎 🔥                │  ← 획득한 뱃지 아이콘
│                             │
└─────────────────────────────┘
```

- XP 바는 항상 보이게 → "조금만 더 하면 레벨업!" 느낌
- 미획득 뱃지는 흐린 아이콘 + 물음표로 표시 → 호기심 유발

## useReward 훅 인터페이스

```javascript
const {
  // 현재 상태
  level,              // 현재 레벨
  title,              // 현재 칭호
  icon,               // 현재 레벨 아이콘
  totalXp,            // 누적 XP
  xpProgress,         // 현재 레벨 내 진행률 (0~1)
  xpToNext,           // 다음 레벨까지 남은 XP

  // 뱃지
  earnedBadges,       // 획득한 뱃지 배열
  allBadges,          // 전체 뱃지 목록 (미획득 포함)
  badgeProgress,      // "4/10 수집" 같은 요약

  // 액션
  addXp,              // (amount) → XP 추가, 레벨업 여부 반환
  checkBadges,        // (context) → 새로 획득한 뱃지 배열 반환
  
  // 이벤트
  pendingLevelUp,     // 레벨업 대기 중 여부 (화면 표시용)
  pendingBadges,      // 새 뱃지 대기 목록 (화면 표시용)
  clearPending,       // 표시 완료 후 대기 초기화
} = useReward();
```

## 완료 기준

- 정답, 힌트 후 정답, 퀴즈 완료, 만점, 복습 완료에 대한 XP 규칙이 스펙대로 반영된다.
- `eduapp_reward`에는 현재 레벨, 칭호, 누적 XP, 다음 레벨 기준, 뱃지 정보가 일관되게 저장된다.
- 레벨업과 뱃지 획득은 중복 없이 감지되고, 결과 화면 또는 대시보드에서 확인할 수 있다.
- 홈 대시보드에서 현재 레벨, XP 진행 바, 뱃지 수집 상태를 확인할 수 있다.
- 오답에는 벌점이 없고, 보상 시스템이 학습 흐름을 끊지 않는 방식으로 동작한다.

## 실패/중단 조건

아래 중 하나라도 발생하면 이 스펙은 완료로 보지 않는다.

- XP가 음수로 내려가거나 레벨 기준과 맞지 않게 계산된다.
- 같은 뱃지가 중복 지급되거나, 레벨업/뱃지 이벤트가 여러 번 반복된다.
- 보상 상태가 `eduapp_reward`에 저장되지 않아 새로고침 후 사라진다.
- 오답에 벌점이 적용되거나, 보상 연출이 퀴즈 결과 흐름을 심하게 방해한다.

## 리스크 & 주의사항

| 리스크 | 대응 |
|--------|------|
| XP 인플레이션 (너무 쉽게 레벨업) | 초반은 의도적으로 빠르게, 후반 간격 넓힘 |
| 뱃지에 집착해서 학습 목적 흐림 | 뱃지 조건을 학습 행동에 연결 (도전, 복습, 습관) |
| 레벨업이 너무 느려서 흥미 저하 | 레벨 1→2는 퀴즈 1회면 충분하게 설계 |
| 숨김 뱃지 달성 불가 시 좌절 | 숨김 뱃지는 자연스럽게 달성 가능한 것만 |
| 보상 없는 날의 허전함 | XP 바가 항상 "다음 레벨까지 얼마나" 보여줌 |
