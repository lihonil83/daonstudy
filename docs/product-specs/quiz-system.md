# Product Spec: 퀴즈 시스템

## 개요

모든 학습의 기본 단위. 문제를 출제하고, 풀고, 피드백을 받는 핵심 기능이다.

---

## 퀴즈 흐름

```
단원 선택 → 퀴즈 시작 → 문제 출제 (1문제씩)
                              ↓
                        선택지 고르기
                              ↓
                   정답 → 🎉 축하 이펙트 + XP 획득 → 다음 문제
                   오답 → 💡 힌트 표시 → 다시 시도 (최대 2회)
                              ↓
                        2회 다 틀림 → 정답 공개 + 오답노트 저장
                              ↓
                        마지막 문제 → 결과 화면
```

---

## 퀴즈 설정

| 항목 | 값 | 이유 |
|------|-----|------|
| 1회 문제 수 | 10문제 | 집중력 유지 적정선 |
| 출제 방식 | 랜덤 셔플 | 반복해도 신선함 유지 |
| 선택지 수 | 4개 | 너무 적으면 찍기 쉽고, 많으면 부담 |
| 힌트 횟수 | 2회 | 1차 힌트 → 2차 힌트 → 정답 공개 |
| 시간 제한 | 없음 | core-beliefs: 자기 속도로 |

## 문제 유형

### MVP: multiple-choice (4지선다)

```json
{
  "id": "mul3-005",
  "type": "multiple-choice",
  "question": "3 × 5 = ?",
  "choices": [12, 15, 18, 20],
  "answer": 15,
  "hints": [
    "3을 5번 더해봐!",
    "3 + 3 + 3 + 3 + 3 = ?"
  ]
}
```

- 선택형 문제는 필요할 때 `visual` 필드를 가질 수 있다.
  예: 시계 읽기 단원의 `{ "visual": { "type": "clock", "hour": 3, "minute": 30 } }`
  예: 파닉스 단원의 `{ "visual": { "type": "phonics-card", "upper": "A", "lower": "a", "soundLabel": "첫소리 A/a" } }`
  예: 단위 학습 단원의 `{ "visual": { "type": "measurement-card", "category": "length", "title": "120 cm" } }`
- 단원 문제는 정적 JSON일 수도 있고, 덧셈/뺄셈처럼 `generateQuestions`로 실행 시점에 만들어질 수도 있다.
- 파닉스 카드처럼 소리가 중요한 단원은 브라우저가 지원할 때 `소리 듣기` 액션을 함께 제공할 수 있다.

### 향후 추가: matching (짝 맞추기)

```json
{
  "id": "alpha-match-001",
  "type": "matching",
  "question": "대문자와 소문자를 짝지어봐!",
  "pairs": [
    { "left": "A", "right": "a" },
    { "left": "B", "right": "b" },
    { "left": "C", "right": "c" }
  ]
}
```

### 향후 추가: text-input (직접 입력)

```json
{
  "id": "mul7-003",
  "type": "text-input",
  "question": "7 × 3 = ?",
  "answer": 21,
  "acceptableAnswers": ["21"],
  "hints": [
    "7을 3번 더해봐!",
    "7 + 7 = 14, 거기에 7을 더하면?"
  ]
}
```

## 화면별 상세

### 1. 단원 선택 화면

- 과목별 단원 카드 목록 (예: 구구단 2단, 3단, ...)
- 각 카드에 진도 표시 (⭐ 최고점수, 완료 여부)
- 카드 탭 → 바로 퀴즈 시작

### 2. 문제 풀기 화면

```
┌─────────────────────────────┐
│  ★ 3/10                    │  ← 진행률
│                             │
│      3 × 5 = ?              │  ← 문제
│                             │
│  ┌──────┐  ┌──────┐        │
│  │  12  │  │  15  │        │  ← 선택지 (큰 버튼)
│  └──────┘  └──────┘        │
│  ┌──────┐  ┌──────┐        │
│  │  18  │  │  20  │        │
│  └──────┘  └──────┘        │
│                             │
└─────────────────────────────┘
```

- 선택지 버튼은 크고 터치 친화적
- 정답 시: 버튼 초록색 + 🎉 이펙트 + "정답!" 텍스트 (1초 후 다음 문제)
- 오답 시: 버튼 빨간색 + 흔들림 애니메이션 + 힌트 말풍선 표시
- 2차 시도도 오답: 정답 초록색 표시 + "아깝다! 정답은 15야. 다음엔 맞출 수 있어!"
- 파닉스 단원은 가능하면 카드 아래에 `소리 듣기` 버튼을 제공하고, 미지원 브라우저에서는 안내 문구만 보여준다.

### 3. 결과 화면

```
┌─────────────────────────────┐
│                             │
│     🎉 퀴즈 완료!           │
│                             │
│     8 / 10 정답             │
│     ⭐⭐⭐ (별 3개!)        │
│                             │
│     +80 XP 획득!            │
│     [만점 보너스 없음]       │
│                             │
│  ┌──────────┐ ┌──────────┐ │
│  │ 다시하기  │ │   홈으로  │ │
│  └──────────┘ └──────────┘ │
│  ┌──────────────────────┐  │
│  │  틀린 문제 복습하기   │  │
│  └──────────────────────┘  │
└─────────────────────────────┘
```

- 별 등급: 10/10 = ⭐⭐⭐, 7~9 = ⭐⭐, 4~6 = ⭐, 0~3 = 격려 메시지
- 맞힌 개수를 크게 강조 (틀린 개수는 작게 또는 표시 안 함)
- "틀린 문제 복습하기" 버튼으로 오답 복습 페이지 연결

## 데이터 흐름

```
[퀴즈 시작]
  → data/math/multiplication-3.json 로드
  → 문제 배열 셔플
  → useQuiz 훅이 상태 관리

[문제별 결과]
  → 정답: score +1, XP +10
  → 오답(힌트 후 정답): score +1, XP +5
  → 오답(최종): score +0, 오답노트에 저장

[퀴즈 완료]
  → eduapp_scores에 결과 저장
  → eduapp_reward에 XP 반영
  → 오답 있으면 eduapp_wrong에 저장
```

## useQuiz 훅 인터페이스

```javascript
const {
  currentQuestion,    // 현재 문제 객체
  questionIndex,      // 현재 문제 번호 (0부터)
  totalQuestions,     // 전체 문제 수
  score,              // 현재 맞힌 수
  isShowingHint,      // 힌트 표시 중 여부
  hintText,           // 현재 힌트 텍스트
  attemptCount,       // 현재 문제 시도 횟수
  isComplete,         // 퀴즈 완료 여부
  result,             // 완료 시 결과 { score, total, xpEarned, wrongAnswers }
  submitAnswer,       // (선택한 답) → 정답/오답 판정
  nextQuestion,       // 다음 문제로 이동
  restart,            // 같은 단원 다시 시작
} = useQuiz(unitId);
```

## 완료 기준

- 단원 선택 후 퀴즈가 시작되고, 한 번의 플레이에서 10문제가 순서대로 진행된다.
- 문제와 선택지는 매 플레이마다 셔플되며, 현재 진행 번호와 남은 흐름이 화면에서 보인다.
- 오답 시 힌트가 최대 2회까지 단계적으로 노출되고, 최종 오답이면 정답 공개 후 다음 문제로 넘어간다.
- 퀴즈 종료 시 결과 화면에서 점수, 별 등급, XP 획득량, 복습 진입 버튼을 확인할 수 있다.
- 퀴즈 결과가 `eduapp_scores`, `eduapp_reward`, `eduapp_wrong` 흐름과 연결된다.

## 실패/중단 조건

아래 중 하나라도 발생하면 이 스펙은 완료로 보지 않는다.

- 문제 데이터가 부족하거나 필수 필드가 없어 퀴즈를 정상 시작할 수 없다.
- 힌트가 2단계로 동작하지 않거나, 최종 오답 후 정답 공개 흐름이 끊긴다.
- 결과 화면 없이 플레이가 종료되거나, 점수/XP/오답 데이터가 후속 시스템으로 전달되지 않는다.
- 같은 플레이에서 문제 수가 10문제가 아니거나, 진행률 표시가 실제 상태와 다르다.

## 리스크 & 주의사항

| 리스크 | 대응 |
|--------|------|
| 문제 데이터가 부족하면 같은 문제 반복 | 단원당 최소 20문제 준비, 10문제 랜덤 출제 |
| 힌트가 답을 너무 직접적으로 알려줌 | 1차 힌트는 방향만, 2차 힌트는 구체적으로 |
| 선택지 배치가 항상 같으면 위치 외움 | 선택지도 매번 셔플 |
| 오답 시 좌절감 | core-beliefs 톤 & 보이스 준수 |
