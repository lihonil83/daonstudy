# MVP 실행 계획

## 목표

아들이 **실제로 앉아서 문제를 풀 수 있는 상태**를 최소한으로 빠르게 만든다.
완벽함보다 동작하는 경험을 먼저 만들고, 단계적으로 확장한다.

---

## Phase 1 — 뼈대 세우기

> 목표: Windows 로컬 브라우저에서 빈 앱 구조와 페이지 이동이 정상 동작

### 할 일

- [ ] Vite + React 프로젝트 초기 세팅
- [ ] `vite.config.js`에 `base: './'` 설정
- [ ] React Router v6 + **HashRouter** 설정 (홈/수학/영어/복습/진도)
- [ ] 폴더 구조 생성 (`pages`, `components`, `data`, `hooks`, `utils`)
- [ ] 공통 레이아웃 + 네비게이션
- [ ] CSS 변수, 폰트, 기본 스타일 적용
- [ ] macOS에서 빌드 후 Windows에서 `dist/index.html` 직접 실행 확인

### 완료 기준

`dist` 파일을 Windows 브라우저에서 열었을 때 페이지 이동이 정상 동작한다.

---

## Phase 2 — 퀴즈 엔진

> 목표: MVP 범위인 **수학 구구단 + 영어 알파벳** 퀴즈를 실제로 풀 수 있는 상태

### 할 일

- [ ] 퀴즈 JSON 스키마 확정 및 데이터 작성 (구구단/알파벳 단원)
- [ ] `useQuiz.js` 훅 구현 (출제, 정답 판정, 힌트 2회)
- [ ] 퀴즈 UI 구현 (문제 카드, 선택지, 피드백, 결과 화면)
- [ ] 수학/영어 페이지에 단원 선택 및 퀴즈 연결
- [ ] 점수 계산 및 퀴즈 결과 데이터 생성

### 완료 기준

구구단 10문제, 알파벳 10문제를 풀고 결과 화면을 확인할 수 있다.

### 퀴즈 JSON 스키마 (MVP)

```json
{
  "id": "mul3-005",
  "type": "multiple-choice",
  "question": "3 × 5 = ?",
  "choices": [12, 15, 18, 20],
  "answer": 15,
  "hints": [
    "3을 5번 더해봐!",
    "3 + 3 + 3 + 3 + 3 = ?"
  ]
}
```

- 힌트는 `hint`(문자열) 대신 `hints`(문자열 배열) 사용
- 1차 힌트 → 2차 힌트 → 정답 공개 흐름 고정

---

## Phase 3 — 기록 + 보상 + 오답복습

> 목표: 퀴즈 결과가 저장되고, 보상과 복습 흐름까지 연결된 MVP 완성 상태

### 할 일

- [ ] `storage.js` 유틸리티 구현 (localStorage 래퍼)
- [ ] `useProgress.js` 구현 (점수 저장, 연속 학습, 최근 기록)
- [ ] `useReward.js` 구현 (XP, 레벨업, 뱃지)
- [ ] `useWrongAnswers.js` 구현 (오답 저장, 복습 상태 관리)
- [ ] 홈 대시보드에 레벨/XP/오답 알림 표시
- [ ] 진도 페이지에 단원별 기록/최근 퀴즈 표시
- [ ] 복습 페이지에 미복습 오답 기반 퀴즈 연결

### 완료 기준

퀴즈 → 점수 저장 → XP/레벨업 → 오답 복습 흐름이 모두 동작한다. (**MVP 완성**)

---

## Phase 4 — 단원 확장

> 목표: MVP 이후 콘텐츠를 점진적으로 확장

### 후보 단원

- 영어: 기초 단어 (동물, 색깔)
- 수학: 시계 읽기
- 영어: 파닉스
- 수학: 길이/무게 단위

### 단원 추가 체크리스트

- [ ] JSON 데이터 파일 작성 (20문제 이상)
- [ ] 단원 레지스트리에 등록
- [ ] 전용 UI 필요 시 컴포넌트 추가
- [ ] 관련 뱃지 조건 업데이트

---

## Phase 5 — 품질 개선

> 목표: 아이가 도움 없이 혼자 사용할 수 있는 완성도 확보

### 할 일

- [ ] 사운드 효과 추가 (정답/오답/레벨업)
- [ ] 애니메이션 다듬기 (정답/결과/레벨업)
- [ ] 학습 통계 시각화 개선
- [ ] 문제 자동 생성/난이도 조절 검토
- [ ] 데이터 백업/복원 기능 추가
- [ ] 오프라인 품질 개선 (PWA 등)

### 완료 기준

아이가 스스로 시작하고, 반복 사용해도 흐름이 끊기지 않는다.

---

## Phase 순서 요약

```
Phase 1: 뼈대 세우기
Phase 2: 퀴즈 엔진 (구구단 + 알파벳)
Phase 3: 기록 + 보상 + 오답복습  ← MVP 완료
Phase 4: 단원 확장
Phase 5: 품질 개선
```

> 각 Phase 종료 시점마다 Windows 환경에서 빌드 실행 테스트를 수행한다.
